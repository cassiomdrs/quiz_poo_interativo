# 🎯 Quiz Interativo de Programação Orientada a Objetos (POO)

Este repositório contém uma aplicação web interativa desenvolvida com **HTML5, Tailwind CSS e JavaScript (Vanilla JS)** para testar e consolidar os conhecimentos nos pilares fundamentais da **Programação Orientada a Objetos**: **Classe, Atributo, Construtor e Objeto**.

## 📌 Visão Geral do Projeto

O objetivo principal deste projeto é servir como uma ferramenta didática leve, responsiva e dinâmica para estudantes e desenvolvedores iniciantes fixarem a diferença prática entre os quatro conceitos centrais da POO através de **50 perguntas técnicas e situações-problema**.

### 🌟 Funcionalidades Principais

* **Ordem Aleatória (Shuffle):** A cada novo acesso ou ao reiniciar o quiz, as 50 perguntas são totalmente embaralhadas automaticamente.
* **Mobile-First & Responsivo:** Interface moderna (Dark Mode) otimizada tanto para telas pequenas (smartphones) quanto para computadores desktop.
* **50 Perguntas Variadas:** Inclui casos de uso do mundo real, analogias e trechos de código em Java e JavaScript.
* **Alternativas Padronizadas:** As opções de resposta de todas as perguntas são focadas estritamente em: `Classe`, `Atributo`, `Construtor` e `Objeto`.
* **Feedback Visual Instantâneo:** Ao clicar na opção, a resposta errada fica em **vermelho** e a correta é destacada em **verde** imediatamente.
* **Barra de Progresso:** Acompanhamento em tempo real do avanço pelas 50 perguntas.
* **Resultado e Porcentagem Final:** Apresentação da pontuação final em porcentagem (%), contagem exata de acertos/erros e feedback didático.

## 🧠 Conceitos Abordados no Quiz

| Conceito | Descrição |
| --- | --- |
| **Classe** | A planta baixa ou molde de código que define a estrutura de dados e regras. |
| **Atributo** | As variáveis e características internas pertencentes ao objeto/classe. |
| **Construtor** | O método especial executado na instanciação (`new`) para inicializar o objeto. |
| **Objeto** | A instância real e viva criada na memória RAM a partir de uma classe. |
